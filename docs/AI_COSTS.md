## Longer Gemini recordings with local synchronization

Enable **Prepare longer recordings and synchronize on this computer** in Teaching and voice. The narrator remains Gemini/Achird. New text is grouped across paragraphs and activities into blocks of at most 2,400 characters, 420 words and 6,000 UTF-8 bytes, whichever comes first. One block is one Google request. This is deliberately below the model's full context/output limits; a whole short lesson may fit one block, while a longer lesson uses several. Playback files and generation requests are separate: local cuts at activity boundaries preserve every response stop without making an additional provider call. The current Q guide plans three blocks instead of 39 legacy parts; that is a request-count reduction, not a promise of the same percentage reduction in token charges.

The server saves each purchased WAV before local synchronization, then aligns the known script using pinned Wav2Vec2 ONNX CTC models. Sentence highlighting uses measured audio positions. It rejects unsupported spoken forms, mismatched/low-confidence audio, incomplete coverage and invalid timings. Uncertain alignment stays pending with the raw audio retained. Retrying that local step does not purchase the audio again. Mathematics and unfamiliar letter pronunciations may require checked spoken forms or further language support; timings are never guessed from text length. Existing complete recordings are reused and are not regenerated automatically.

Install on another host with the server Python: `pip install -r backend/requirements-voice-alignment.txt`, then `python backend/tools/install_voice_alignment.py`. Models are installed explicitly under local `data/models/narration-alignment-v1`, with pinned revisions, SHA-256 checks and source URLs in `assets.json`. English model: [ONNX Wav2Vec2 base](https://huggingface.co/onnx-community/wav2vec2-base-960h-ONNX). Portuguese model: [ONNX Wav2Vec2 Portuguese](https://huggingface.co/onnx-community/wav2vec2-large-xlsr-53-portuguese-ONNX). No microphone recording, external transcription service or separate alignment API charge is involved. Test Mode shares these host models and the family spending ledger while retaining its isolated learner records.

For offline diagnosis, `python backend/tools/align_narrator.py --audio saved.wav --script script.json --language pt-BR --output output-folder` writes timings and bounded clips without opening the learner database or contacting a provider. The JSON is a list of sentence objects with `text`, or an object containing `sentences` and optional `activities` with `start_sentence` indices.

The voice worker paces requests and preserves provider quota/rate-limit responses. It imposes no local daily ceiling. Other clients of the Google project are not visible, so provider responses remain authoritative. Unknown purchase outcomes are retained rather than blindly repurchased. Retry an older paused job from the lesson preparation bar.
